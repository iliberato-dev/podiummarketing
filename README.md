# PODIUM Inteligência Empresarial

Site estático feito com HTML, CSS e JavaScript. Não requer Node.js, npm, instalação de pacotes nem etapa de build: abra `index.html` ou publique os arquivos em um servidor web.

- `styles.css`: estilos personalizados e responsivos.
- `assets/site.css`: estilos utilitários estáticos usados pelas páginas.
- `header.js` e `script.js`: navegação compartilhada e menu mobile.

## Publicação

Publique a pasta do site em um servidor HTTPS. Para prévias de compartilhamento em redes sociais, atualize as URLs relativas `og:image` dos HTML para a URL HTTPS pública absoluta da imagem depois de definir o domínio do site.
